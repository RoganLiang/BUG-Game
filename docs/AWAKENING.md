# 0.4.0 六題覺醒（新章）

依使用者分享的[設計討論](https://chatgpt.com/share/6af97b58-ace8-83ee-9d46-4b3a84206a84)擷取與本遊戲相關規則，不保存整份對話或其他作品內容。

六題連續故事、每題五選項、固定預寫因果，允許安全退出。司機害怕重複遇見主角；西裝男察覺重複；車上與站旁婦人是同一人，不是雙胞胎。圖書館員不在第一題提前揭露。這是覺醒序章，不是完整海龜湯解謎引擎；迴圈起因仍未揭曉。

依 observe/care/adapt/resolve/coordinate 的六次累計選擇決定五種預寫能力；同分用最近一次屬於最高分策略的選擇。不是選水就得水能力，也不是人格診斷或即時生成無限能力。六題之後可試用一次，精力扣4；無永久帳號綁定。

## 模型與邊界

scenarioId、awakening（route/scores/answers/powerId/used）加入GameState；六題用穩定節點ID awakening-0到5，終點awakening-result。重播合法選項恢復存檔，不信任外部數值。新章使用0.4.0，舊章保留0.2.0。UI不讀內部worldState，未見證人與未解鎖情報不顯示。

六種開場事件搭配共用公車故事，四種路線；不是25個獨立完整劇本。六語為翻譯初稿，尚無真人趣味性或實體手機測試。Supabase專案已建立但未接入，沒有啟用遠端玩家統計。
