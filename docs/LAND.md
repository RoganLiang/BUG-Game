# 無城之地：0.5.0 重建沙盤

2026-11-15使用者要求：地點必須與地理環境、實際玩法相連；參考《世紀帝國》從土地採集與建造的方向，起始沒有城市。採用可回退的原型決策：保留六題覺醒，後接獨立、無既有城市的單人回合沙盤。不是宣告現實城市毀滅，也不是取代《電梯》的作者主線。

## 已實作

- 六題結束可點「帶著能力，進入無城之地」。已完成／已試用能力的0.4存檔可直接繼續，無須重抽。
- 25個故事落點對應固定種子地圖與六種手工環境模型。出生地仍是獨立背景欄位，不覆蓋現居或本輪落點。
- 6×6地塊：平原、森林、淡水、丘陵、海水、乾地。每塊可採資源存量有限；海水不能當飲水。
- 地圖開局零建築。營地只能建平原／丘陵；取水站需在已知淡水旁的平原；菜圃需先有取水站且在平原。木石水有實際成本。
- 每3工作輪生產及消耗。菜圃產量依環境為2、3或4；缺食／缺水降低聚落安定。
- 第4輪依環境出現暴雨／乾風／寒夜；暴雨損失取決於菜圃是否臨河與是否加固。第8輪是空箱敲擊謎題，觀察或壓箱會留下不同情報／成本。尚未完成重建者第12輪可遇見旅人。
- 五種微型能力使用既有限制內的小動作協助勘查，揭開5格；普通勘查3格。每次能力消耗4能量，間隔3工作輪；休息恢復6但仍消耗時間。
- 完成營地、取水站、菜圃，且第9輪起食物／飲水各至少4，即為本輪成功。第18輪未完成記錄為未完成；安定降到0失敗。結束後地圖及紀錄保留，重設需確認。
- 存檔沿用0.4格式／既有鍵，新增可選land欄位，從決策重播，不信任外部修改的資源、地圖與能量。未探索地塊在playerView投影為fog。
- 六語初稿、44px地塊、方向鍵與可見焦點；無需後端、聲音或付費服務。

## 地理資料邊界

環境分類與數值是作者設計的簡化遊戲參數，沒有讀入GIS、高程、即時天氣或人口資料；不能用來推論實際城市的土地、建築或生活條件。阿拉斯加／馬達加斯加仍維持區域名稱，不擅指定城市。同一教學起步區保證水、木、可耕平原可達，其餘地塊依落點種子變化。出生地不決定人格或種族天賦。

## 限制與後續

目前是18工作輪、36格的小型策略原型，不是完整世紀帝國式RTS：沒有軍隊、建築計時、連續大地圖、多人、跨玩家共享土地或伺服器在線統計。這是覺醒後的實際延續玩法，不是《公車》迴圈謎底或《電梯》已定稿機制。後續可逐個加入有固定謎底、環境觸發、能力用途與結果的原創事件，不以事件清單代替已完成內容。
